## 做出的决定

### 框架选型：Flask（本人确认）
- 原因：Jinja2 模板可无缝承接现有 HTML/CSS/JS，视觉效果 100% 保留
- 对比 Django：过重，不适合个人主页
- 对比 FastAPI：偏 API 导向，模板渲染不如 Flask 方便
- 对比 Streamlit：UI 控制力弱，会丢失现有精美设计（本人之前用过 Streamlit，理解差异后选择 Flask）

### 数据存储：JSON 文件（`data/` 目录）
- 零运维开销，直接编辑修改内容
- 以后可平滑迁移到数据库

### 部署平台：Render（render.com）
- 与 Streamlit 的区别：Streamlit 是框架，Render 是部署平台
- 免费套餐：750 小时/月，自动 HTTPS，Git 推送自动部署
- 备选：PythonAnywhere

### 改造原则
- CSS/JS 原封不动提取到独立文件
- HTML 结构保持不变，仅硬编码文字替换为模板变量
- 保留原 `index.html` 作为视觉参考

### 会话历史方案
- `conversations/` 目录，文件命名：`YYYY-MM-DD-主题.md`
- 每次对话结束写入摘要
